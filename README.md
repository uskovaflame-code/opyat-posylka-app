# Это последнее, честно 📦

Личный учёт покупок из Китая: посылки, клиенты, юани → рубли, доставка по весу, поиск треков, цветные отметки и Excel.

[Открыть приложение](https://uskovaflame-code.github.io/opyat-posylka-app/) · [Инструкция](USER-GUIDE.md)

Бесплатная статическая версия для GitHub Pages. Сервер и токен бота для работы этой версии не нужны. Публикуются только файлы приложения; покупок в репозитории нет.

В Telegram Mini App записи сохраняются в Telegram CloudStorage отдельно для каждого пользователя данного бота. В обычном браузере записи сохраняются только в этом браузере на этом устройстве. Эти два хранилища независимы. Не редактируйте одно облачное сохранение одновременно с разных устройств; сохраняйте резервную JSON-копию.

## Публикация

GitHub Settings → Pages → Deploy from a branch → main → /docs → Save.

В BotFather выберите @opyatposylka_bot → Bot Settings → Configure Mini App → Enable Mini App и укажите адрес приложения. Названия пунктов могут отличаться в интерфейсе BotFather. Также можно настроить Menu Button с этим адресом.

## Состав

В docs находятся все файлы статической версии. Она запускается пустой. Кнопка «Поделиться» передаёт только ссылку, без покупок. Инструкция доступна также внутри приложения.
