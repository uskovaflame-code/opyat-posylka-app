# Бесплатное размещение

Готовая статическая версия находится в docs/. Она не требует Node.js, базы на сервере или токена бота.

1. Разместите docs/ на GitHub Pages: Settings → Pages → main → /docs → Save.
2. В BotFather откройте настройки @opyatposylka_bot и включите Main Mini App с URL https://uskovaflame-code.github.io/opyat-posylka-app/.
3. При необходимости настройте Menu Button на тот же URL.
4. Откройте мини-приложение из бота. Облачное хранение работает в поддерживаемом клиенте Telegram. Прямая ссылка в браузере использует отдельное локальное хранилище.

Не помещайте в публичный репозиторий токены, базы, резервные копии или личные покупки.
